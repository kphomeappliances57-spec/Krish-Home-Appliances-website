# Krish Home Appliances

A highly optimized, mobile-first Next.js single-page application built for Krish Home Appliances, a multi-brand home appliance repair service and genuine spare parts shop located in Nalasopara East, Maharashtra.

## Overview

The primary business goal is to outrank basic local competitors by highlighting a unique dual value proposition: a physical storefront for genuine spare parts combined with expert multi-brand doorstep repair services.

## Technical Architecture

- **Framework**: Fast, functional React components via [Next.js 15 (App Router)](https://nextjs.org/).
- **Language**: [TypeScript](https://www.typescriptlang.org/) for robust type safety.
- **Styling**: [Tailwind CSS v4](https://tailwindcss.com/) for fluid, mobile-first responsive utilities.
- **Animations**: [Framer Motion](https://www.framer.com/motion/) (`motion/react`) for purposeful transitions and interactive UX.
- **Icons**: [Lucide React](https://lucide.dev/) for crisp, scalable vector icons.
- **SEO Optimization**: 
  - Dynamic `robots.txt` and `sitemap.xml` generated via Next.js Metadata API.
  - Granular Page Metadata incl. OpenGraph for broad local indexing.
  - Semantic HTML5 structure (Targeting < 2.0s LCP).
  - Programmatically injected `LocalBusiness` and `FAQPage` JSON-LD Structured Data Schema.

## Core Features

1. **Strategic Local SEO Strategy**: Keywords deeply woven into the copy (e.g., "AC repair Nalasopara", "Daikin AC service Nalasopara") alongside dual schema markup to capture long-tail search traffic and rich snippets.
2. **True Mobile-First UX**: Cross-browser layout shifts eliminated (100dvh baseline, disabled tap highlights) and supplemented with a persistent mobile action bar holding thumb-accessible CTAs ("WhatsApp Us" & "Call Now").
3. **Immersive Brand Hub**: 
   - A highly visible announcement banner.
   - Animated multi-brand hardware ticker.
   - Comprehensive Services capability showcase (AC, Fridge, Washing Machine, Microwave).
   - "Inside the Hub" visual representations.
   - Smooth local interactions with accordion-style FAQs and integrated lazy-loaded Google Maps embedding.
4. **Transparent Trust Builders**: Highlighted GST registration, explicit spare parts availability, simple workflow layouts, and pricing baseline placeholders (e.g., "Visits from ₹299").
